Find. Verify.
Rewrite.

// smash runs once a day in the background (launchd on macOS, a systemd timer on Linux) and only looks at what's new since the last run. Only suspicious lines ever leave your machine, and every answer is checked before a byte is changed.

01 / FIND

Filter locally

Key formats, KEY=value, bearer tokens, URL credentials and high-entropy strings are spotted on your machine.

02 / ASK

Model confirms

Suspicious lines go to OpenAI or Anthropic in batches. Only lines with a real secret come back, masked.

03 / VERIFY

Nothing else changes

An answer is used only if it's the original line with spans replaced by [REDACTED].

04 / REWRITE

Atomic, in place

Files are rewritten byte-for-byte except the redactions. Lines appended mid-run are kept.

What ships

  • Preview firstSee counts per source and confirm before anything is sent.
  • IncrementalOnly new lines are checked; clean ones are never re-sent.
  • Today staysLines dated today wait for tomorrow's run.
  • Live sessions skippedAgent logs touched in the last hour are left alone.
  • Catches upA missed run happens after sleep or reboot.
  • Audit logsmash log shows files and counts, never the text.

Stay in control

Manual runs onlymacOS

# remove the daily job, keep smash
launchctl bootout gui/$(id -u) \
  ~/Library/LaunchAgents/com.smash.daily.plist
rm ~/Library/LaunchAgents/com.smash.daily.plist
smash run   # whenever you like

Manual runs onlyLinux

# remove the daily timer, keep smash
systemctl --user disable --now smash.timer
rm ~/.config/systemd/user/smash.{service,timer}
systemctl --user daemon-reload
smash run   # whenever you like

Uninstall everythingmacOS & Linux

smash uninstall   # job, ~/.smash, binary; asks first

Redaction is permanent and smash keeps no backups. Rotate any key it finds: if it was on disk, assume it was read.
